# Rapport QA — AI Session Planner v2 (plan éditable + Add & start)

Date : 2026-07-24 · Build testé : prod local (`next build && next start -p 3999`) · Outil : playwright-cli · Appels API réels (Claude Haiku)

## Périmètre

Refonte du AI Session Planner : question unique localisée, écran de revue éditable (renommer, stepper ± pomodoros, supprimer, ajouter, réordonner), total live pauses comprises, deux sorties "Ajouter N tâches" / "Ajouter et démarrer". Backend : validation Zod + normalisation de la réponse Claude. Câblage : `importAITasks` retourne les ids, handler add & start, guard clavier modal.

## Parcours validés ✅

- **Écran question** : question française (aiLanguage défaut "fr"), textarea auto-focus, bouton Générer disabled si vide, placeholder localisé.
- **Génération** : plan réel Claude (5 générations testées), objectif reformulé + tip affichés, total exact — "8 pomodoros ≈ 4 h 05, pauses comprises" = valeur théorique de la formule (25/5/15 min, pause longue toutes les 4).
- **Édition** :
  - Stepper : total live recalculé à chaque clic ; − disabled à 1, + disabled à 8 ; bornes ↑/↓ disabled première/dernière ligne.
  - Titre vidé : ring rouge (`ring-red-400/50`), tâche exclue du total et des compteurs, jamais supprimée silencieusement.
  - Réordonner : swap correct (vérifié par ordre des textboxes).
  - Supprimer / Ajouter : compteurs exacts ; ligne ajoutée auto-focus ; Enter → blur.
  - Plan vidé : hint "Ajoute au moins une tâche…", les 2 boutons d'import disabled, "Recommencer" actif.
  - "Recommencer" conserve le goal (changement volontaire vs v1).
- **Ajouter et démarrer** (timer idle) : modal fermée, 5 tâches importées (`aiGenerated: true`, ordre du plan préservé), 1ʳᵉ tâche active (ring), timer démarré en mode pomodoro (titre onglet "24:50 - Pomodoro").
- **Ajouter et démarrer** (pomodoro DÉJÀ en cours) : timer intact (23:22 → 23:20, pas de reset), tâches importées + 1ʳᵉ activée. Conforme à la décision produit.
- **Ajouter seulement** : tâches importées, modal fermée, timer resté idle.
- **Pluriels FR** : "Ajouter 0 tâche" (disabled), "Ajouter 1 tâche", "Ajouter N tâches".
- **Fix clavier** : Espace avec un bouton de la modal focusé n'atteint plus le timer derrière (avant le fix, il le démarrait). Espace active le bouton focusé (comportement navigateur normal).
- **Escape** : ferme la modal (plan perdu, assumé v1).
- **Mobile 375 px** : aucun overflow horizontal ; après fix layout, stepper compact (chiffre seul), rationale pleine largeur sous la ligne.
- **Thèmes** : dark et light validés visuellement (screenshots).

## Bugs trouvés et corrigés pendant la QA 🔧

| Bug | Sévérité | Fix |
|---|---|---|
| Layout mobile : rationale écrasée dans une colonne de ~9 caractères, lignes très hautes | Moyenne | `PlanTaskRow` restructuré : rationale pleine largeur sous la ligne, unité pomodoro masquée sur mobile (chiffre seul + `title`) |
| "Ajouter 0 tâches" : pluriel incorrect en français (zéro = singulier) | Mineure | `addOnlyCta` fr : `n >= 2 ? "s" : ""` |
| Tip quasi illisible en light mode (`text-purple-300` sur fond clair) | Mineure (préexistant) | Variable `--accent-text` (dark `#d8b4fe` / light `#7e22ce`) dans globals.css, classe `text-accent-text` |
